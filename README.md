# Encre

Des cartes à lui envoyer par lien : invitations, mots, coupons.
Mobile uniquement, statique (GitHub Pages), sans backend, sans compte.

- Le contenu d'une carte voyage **dans le lien**. Rien n'est stocké sur un serveur.
- Le **journal** des cartes reçues vit en `localStorage`, sur son téléphone.
- Le **carnet d'idées** (lieux, sorties, phrases, coupons) vit dans `data/*.json`, côté dépôt. Il ne part jamais dans un lien.
